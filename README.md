### 🚀 What I've Built

#### 🤖 EduMind: Offline AI Document Assistant · [Live](https://edumind.buildbox.website)
*Summer Intern @ SPTBI*

An AI assistant that answers staff questions across **20 SOP documents / 627 indexed passages**, with a source citation on every answer.

- **Hybrid retrieval:** BGE embeddings + BM25 → Reciprocal Rank Fusion → cross-encoder reranking
- **7-step LangGraph agent** that re-retrieves when answer confidence is low
- Runs **100% offline**: Qwen2.5 7B via Ollama, ChromaDB, Docker
- **4 role-based access levels** enforced per passage, backed by a **570-test** suite

`LangGraph` `LangChain` `ChromaDB` `Ollama` `Qwen2.5` `BGE` `BM25` `Docker`

#### 🏦 SanityScan: Bank Statement Analysis & Loan Underwriting · [Live](https://sanityscan.site)

Turns 6 months of bank statements into an explainable underwriting report in **~20 seconds**.

- **OCR + parsing pipeline** (Python, Tesseract) supporting **8 major Indian banks**
- Reconciles every transaction against closing balance; detects EMIs, cheque bounces, circular transfers
- Configurable scoring engine using AMB, net income, FOIR, DSCR and cash-flow volatility
- Privacy-first: processed in memory, purged within 15 minutes

`Python` `Tesseract` `TypeScript` `Prisma` `PostgreSQL`

#### 🧓 Sonaru: Offline-First Dementia Care App · [Repo](https://github.com/AnupNerurkar/Sonaru)
*Smart India Hackathon 2026*

Android app delivering Cognitive Stimulation Therapy with a rule-based **adaptive difficulty engine**, offline patient mode, and caretaker dashboards in 3 languages.

`Kotlin` `Jetpack Compose` `Firebase`
